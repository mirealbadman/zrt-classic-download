# Zombie Road Trip

**The original Zombie Road Trip gameplay, with controller support for modern Android.**

[Download the Android APK from GitHub Releases](https://github.com/mirealbadman/zrt-classic-download/releases)

The game's original presentation, touchscreen menus, progression, music and gameplay are preserved. The Android compatibility layer helps it run on newer phones; added gamepad controls work during active rides, while the original menus remain touch-operated. Controller and device compatibility can vary.

### Basic controls

- **Left stick / D-pad left and right:** rotate in the air
- **LB / RB or L1 / R1:** rotate left and right
- **A / Cross or RT / R2:** shoot
- **Menus and RIDE:** use the original touchscreen controls

### Installation and saves

Download the APK from Releases and open it on Android. Android may ask for permission to install from your browser or file manager. If updating an installed compatible version, avoid uninstalling first so you don't lose local saves.
